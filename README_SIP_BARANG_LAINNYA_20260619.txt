FITUR BARU: SIP BARANG LAINNYA

Perubahan utama:
1. Menambahkan aplikasi/menu SIP Barang Lainnya.
2. Nomor SIP diinput manual oleh pengguna, tidak dibuat otomatis.
3. Nama barang diinput manual dan dapat lebih dari satu barang.
4. Setiap barang memiliki field Nama Barang, Spesifikasi/Merk/Tipe, Satuan, Jumlah, NUP, Serial Number opsional, dan Keterangan.
5. Tersedia tombol Simpan Draft, Teruskan, Detail, Edit, Export PDF/Excel/CSV.
6. Tersedia menu persetujuan pejabat penandatangan dengan Setujui/Tolak disertai keterangan/alasan.
7. PDF SIP Barang Lainnya memakai logo dan kop Kementerian Sosial sesuai unit kerja pemegang SIP.
8. Preview desain UI dan contoh dokumen disertakan di folder _preview_sip_barang_lainnya.

Setelah ekstrak ZIP jalankan:
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
