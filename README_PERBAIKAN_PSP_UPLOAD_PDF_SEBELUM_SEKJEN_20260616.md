# Perbaikan PSP BMN - Upload Dokumen PSP SIM Pengelolaan BMN PDF sebelum Sekjen

Perubahan:
1. Dokumen PSP SIM Pengelolaan BMN digenerate dalam format Word (.docx) agar nomor surat, redaksi, meterai, dan tanda tangan bisa diedit manual.
2. Nomor surat pada dokumen Word tidak dipaksa otomatis; ditampilkan sebagai titik-titik untuk diisi manual sebelum dokumen difinalkan.
3. Sebelum Biro Umum meneruskan usulan PSP ke Sekjen, wajib upload Dokumen PSP SIM Pengelolaan BMN Final/Gabungan dalam format PDF.
4. PDF tersebut dapat berupa:
   - hasil TTE BSrE,
   - tanda tangan manual,
   - meterai biasa,
   - e-Meterai elektronik.
5. Biro Umum dapat upload PDF final langsung dari halaman Detail PSP pada panel Verifikasi Usulan PSP.
6. Jika tombol Teruskan ke Sekjen diklik tanpa PDF Dokumen PSP SIM Pengelolaan BMN, sistem menolak dan menampilkan pesan wajib upload.
7. Form PSP tetap menyediakan kolom upload Dokumen PSP SIM Pengelolaan BMN Final/Gabungan, namun tidak wajib saat draft/usulan awal.

Alur bisnis:
Unit Kerja/Pengelola BMN membuat PSP -> import barang -> generate dokumen Word -> edit nomor surat/manual -> tanda tangan/meterai -> simpan sebagai PDF -> upload Dokumen PSP SIM Pengelolaan BMN Final/Gabungan -> Biro Umum verifikasi -> Biro Umum teruskan ke Sekjen -> Sekjen menetapkan PSP.
