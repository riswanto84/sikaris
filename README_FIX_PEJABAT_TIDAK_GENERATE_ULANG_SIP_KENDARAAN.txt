Perbaikan alur SIP Kendaraan:
1. Pejabat penerbit SIP Kendaraan tidak lagi melihat tombol Generate Konsep PDF.
2. Generate Konsep PDF hanya untuk Pengelola BMN/pengusul sebelum TTE pegawai calon pemegang SIP.
3. Pejabat penerbit cukup Setujui atau Tolak SIP yang sudah diajukan.
4. Proses Setujui SIP tidak lagi membuat/generate file PDF baru.
5. Upload TTE BSrE pejabat penerbit tidak ditampilkan pada Detail SIP Kendaraan.
