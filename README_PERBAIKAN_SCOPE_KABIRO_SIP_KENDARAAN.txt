PERBAIKAN SCOPE KEPALA BIRO UMUM & TTE BSrE SIP KENDARAAN

1. Kepala Biro Umum tidak lagi melihat semua usulan SIP Kendaraan nasional.
   Daftar persetujuan Kepala Biro Umum dibatasi hanya SIP dari unit kerja di bawah Sekretariat Jenderal.

2. Sekretaris UKE I/UKE II, Kepala Sentra, dan Kepala Balai hanya melihat SIP sesuai unit kewenangan penerbitnya.

3. Pengelola BMN tetap hanya dapat membuat Draft/Konsep dan mengajukan SIP.

4. Pejabat penerbit SIP Kendaraan dapat:
   - melihat daftar pengajuan sesuai kewenangan,
   - generate konsep/draft PDF SIP,
   - menyetujui/menolak SIP,
   - upload file SIP final yang sudah TTE BSrE.

5. Setelah pejabat mengupload file SIP yang sudah TTE BSrE:
   - status SIP menjadi TERBIT,
   - status_tte menjadi SUDAH_TTE,
   - file tersimpan pada file_signed_pdf dan dokumen_sip.

Tidak ada migrasi database baru karena field file_signed_pdf/status_tte sudah tersedia di model terbaru.
