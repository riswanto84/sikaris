PERBAIKAN ALUR SIP RUMAH NEGARA - 16 JUNI 2026

Alur SIP Rumah Negara disamakan konsepnya dengan SIP Kendaraan Dinas:

1. Pengelola BMN membuat Draft/Konsep SIP Rumah Negara.
2. Status tidak lagi dipilih bebas dari Form SIP Rumah Negara.
3. Dokumen SIP Rumah Negara tidak diupload dari form, tetapi digenerate sistem.
4. Pengelola BMN melakukan Generate Konsep PDF.
5. Calon pengguna rumah melakukan TTE pada konsep PDF.
6. Pengelola BMN mengupload file PDF yang sudah TTE calon pengguna rumah.
7. SIP Rumah Negara baru bisa diajukan ke Sekretaris Jenderal setelah file TTE calon pengguna diupload.
8. Sekjen/Admin melakukan Review, lalu Setujui atau Tolak.
9. Jika disetujui, status langsung menjadi TERBIT.
10. Pada status TERBIT, Sekjen/Admin dapat mengupload file final SIP Rumah Negara yang sudah TTE Sekjen/BSrE.
11. Preview PDF menampilkan dokumen versi terakhir: Final TTE Sekjen, lalu TTE calon pengguna, lalu konsep PDF.

Status alur utama:
DRAFT -> DIAJUKAN -> TERBIT
DRAFT/DITOLAK -> dapat diedit ulang oleh Pengelola BMN
DIAJUKAN -> dapat disetujui/ditolak oleh Sekjen
TERBIT -> dokumen final dapat diupload oleh Sekjen/Admin
