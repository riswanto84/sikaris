# Alur Bisnis PSP BMN dan Penghapusan BMN - SIKARIS

## PSP BMN

1. Unit kerja/satker membuat Permohonan PSP BMN dan dapat mengunggah Dokumen Permohonan PSP Gabungan serta import lampiran banyak barang.
2. Biro Umum membuka menu Verifikasi Usulan PSP, memeriksa kelengkapan dan menghasilkan konsep dokumen dari SIKARIS:
   - Nota Dinas Permohonan PSP ke Sekjen: wajib TTE BSrE Kepala Biro Umum.
   - Surat Keterangan Kebenaran Dokumen Digital: wajib TTE BSrE Kepala Biro Umum.
   - Surat Pernyataan Formil dan Materiil: wajib e-Meterai elektronik dan TTE BSrE Kepala Biro Umum.
   - Lampiran Daftar BMN: dihasilkan dari import Excel detail barang.
3. Biro Umum dapat mengembalikan usulan untuk perbaikan atau meneruskan ke Sekjen.
4. Sekjen membuka menu Penetapan PSP, membaca seluruh usulan dari semua unit kerja, lalu menetapkan PSP/SK terbit atau menolak.
5. Dokumen final yang sudah TTE BSrE/e-Meterai diunggah kembali pada detail permohonan sebagai arsip final.

## Penghapusan BMN

1. Unit kerja/satker membuat Permohonan Penghapusan BMN.
2. Jika barang yang dihapus banyak unit, unit kerja mengunduh template Excel dan melakukan import detail barang yang akan dihapus.
3. Biro Umum membuka menu Verifikasi Usulan Penghapusan, memeriksa dokumen dan detail barang, lalu mengembalikan untuk perbaikan atau meneruskan ke Sekjen.
4. Sekjen membuka menu Penetapan SK Penghapusan, menetapkan SK Penghapusan BMN atau menolak usulan.
5. SK/dokumen final hasil TTE BSrE diunggah kembali pada detail permohonan.
