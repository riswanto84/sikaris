# Perbaikan Generate Word SK Penetapan PSP - Sekjen

Perubahan:

1. Pada role Sekjen, tombol generate Word PSP hanya menampilkan **Generate Word SK Penetapan PSP**.
2. Tombol generate Word Nota Dinas, Surat Keterangan Dokumen Digital, dan Surat Pernyataan e-Meterai tidak lagi ditampilkan pada role Sekjen.
3. Generate SK Penetapan PSP dibuat dalam format Word (.docx) dengan struktur mengikuti contoh SK PSP:
   - Keputusan Menteri Sosial Republik Indonesia
   - Nomor SK manual/editable
   - Menimbang
   - Mengingat
   - Memperhatikan
   - MEMUTUSKAN
   - Diktum KESATU sampai KETUJUH
   - Blok tanda tangan Sekretaris Jenderal
   - Salinan keputusan
4. Lampiran daftar barang tidak digenerate pada SK Word Sekjen.
5. Generate Nota Dinas/Surat Keterangan/Surat Pernyataan tetap tersedia untuk alur Biro Umum sebelum diteruskan ke Sekjen.

Tidak ada perubahan struktur database.
