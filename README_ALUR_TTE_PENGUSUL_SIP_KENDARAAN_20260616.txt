PERBAIKAN ALUR TTE PENGUSUL SIP KENDARAAN

Alur baru:
1. Pengelola BMN membuat Draft/Konsep SIP Kendaraan.
2. Pengelola BMN melakukan Generate Konsep PDF.
3. Konsep PDF tersebut ditandatangani secara elektronik oleh pegawai pengusul SIP Kendaraan.
4. Pengelola BMN mengupload file PDF yang sudah TTE pegawai pengusul.
5. Setelah file TTE pengusul terupload, Pengelola BMN baru dapat mengajukan SIP ke pejabat penerbit.
6. Pejabat penerbit melakukan review, setujui/tolak.
7. Jika disetujui, pejabat penerbit melakukan proses TTE BSrE dan upload file final.

Catatan:
- Upload TTE pengusul hanya untuk Pengelola BMN pada status Draft/Konsep atau Ditolak.
- Upload TTE BSrE final tetap hanya untuk pejabat penerbit.
- Terdapat migrasi baru 0010_tte_pengusul_sip_kendaraan.py.
