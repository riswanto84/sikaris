# Perbaikan PSP Role Sekjen - Tanpa Tombol Edit

Perubahan:

1. Role Sekjen pada daftar Permohonan PSP BMN hanya melihat tombol **Detail**.
2. Tombol **Edit**, **Import Barang**, dan **Hapus** disembunyikan untuk Sekjen.
3. Pada Detail PSP, tombol **Edit** disembunyikan untuk Sekjen.
4. Proteksi URL langsung ditambahkan: Sekjen tidak dapat mengakses update, import barang, atau delete PSP melalui URL langsung.
5. Scope baca Sekjen tetap seluruh unit kerja pusat, sentra, dan balai.

Tidak perlu migrasi database.
