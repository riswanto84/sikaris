Perbaikan Detail SIP Rumah Negara:

- Menambahkan form upload file PDF SIP Rumah Negara yang sudah TTE Sekjen/BSrE.
- Form tampil untuk role Sekretaris Jenderal/Admin System ketika status SIP DISETUJUI_SEKJEN, MENUNGGU_TTE, atau TERBIT dan status_tte belum SUDAH_TTE.
- Setelah upload, file disimpan pada file_signed_pdf dan dokumen_sip, status_tte menjadi SUDAH_TTE, dan status SIP menjadi TERBIT.
- Preview Detail SIP menampilkan PDF Final SIP Rumah Negara TTE Sekjen/BSrE sebagai dokumen utama bila sudah tersedia.
