# Perbaikan PSP Role Sekjen - Read & Update Semua Unit Kerja

Perubahan:

1. Role Sekretaris Jenderal dapat melihat semua Permohonan PSP BMN dari seluruh unit kerja, termasuk pusat, Sentra, dan Balai.
2. Form edit PSP untuk Sekjen menampilkan seluruh pilihan Unit Kerja/Satker dan Pegawai/PIC dari semua unit kerja.
3. Field proses PSP seperti status, TTE BSrE, e-Meterai, SK PSP, dan catatan proses tetap muncul untuk Sekjen.
4. Role Sekjen dibatasi hanya READ dan UPDATE, sehingga tombol Hapus disembunyikan dan akses hapus langsung ditolak.
5. Scope Pengelola BMN tetap mengikuti unit/eselon I masing-masing.
