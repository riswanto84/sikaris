# Perbaikan Dokumen PSP dan Rule Nota Dinas Penghapusan BMN

## A. PSP BMN - Dokumen hasil generate SIKARIS

Format hasil generate PDF PSP diperbaiki agar mengikuti contoh dokumen Biro Umum:

1. Nota Dinas Permohonan PSP
   - Kop: Kementerian Sosial RI / Sekretariat Jenderal / Biro Umum.
   - Judul: NOTA DINAS.
   - Nomor menggunakan nomor nota PSP yang tersimpan.
   - Tujuan: Sekretaris Jenderal.
   - Dari: Kepala Biro Umum.
   - Isi dasar hukum dan daftar lampiran mengikuti format contoh.
   - Area tanda tangan Kepala Biro Umum disediakan untuk TTE BSrE.

2. Surat Keterangan Kebenaran Dokumen Digital
   - Kop dan judul mengikuti contoh.
   - Memuat identitas pejabat Kepala Biro Umum.
   - Menyatakan bahwa dokumen arsip digital sesuai asli.
   - Area tanda tangan Kepala Biro Umum disediakan untuk TTE BSrE.

3. Surat Pernyataan Formil dan Materiil
   - Kop dan judul mengikuti contoh.
   - Memuat identitas pejabat Kepala Biro Umum.
   - Memuat pernyataan tanggung jawab kebenaran formil dan materiil BMN.
   - Memuat area e-Meterai elektronik.
   - Area e-Meterai ditempatkan berdampingan dengan area TTE/QR BSrE dan tidak saling menimpa.

4. Lampiran Daftar BMN
   - Tetap menggunakan data hasil import Excel PSP.
   - Duplicate build PDF dihapus agar PDF tidak error.

## B. Penghapusan BMN - Rule tujuan nota dinas

Rule yang diakomodir pada detail penghapusan:

1. Sentra di bawah Ditjen Rehabilitasi Sosial
   - Dari: Kepala Sentra.
   - Tujuan nota dinas: Direktur Jenderal Rehabilitasi Sosial.
   - Catatan: selanjutnya diproses berjenjang sesuai kewenangan menuju penetapan Sekjen.

2. Balai
   - Dari: Kepala Balai.
   - Tujuan nota dinas: Sekretaris Jenderal.

3. Unit pusat / Eselon I
   - Dari: Sekretaris Unit Eselon I.
   - Tujuan nota dinas: Sekretaris Jenderal.

Informasi rule ini ditampilkan di halaman Detail Permohonan Penghapusan BMN agar verifikator Biro Umum dan Sekjen memahami alur dokumen yang benar.
