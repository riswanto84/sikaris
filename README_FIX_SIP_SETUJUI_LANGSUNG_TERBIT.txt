Perbaikan alur SIP Kendaraan:

1. Pejabat penerbit SIP Kendaraan hanya Setujui/Tolak.
2. Saat tombol Setujui SIP diklik, status SIP langsung menjadi TERBIT.
3. Pejabat tidak generate ulang PDF dan tidak upload ulang PDF.
4. Dokumen final yang dipreview pada Detail SIP Kendaraan menggunakan file TTE pegawai calon pemegang SIP yang sudah diupload Pengelola BMN.
5. Pada daftar Persetujuan Pejabat Penerbit SIP Kendaraan, SIP berstatus TERBIT tidak menampilkan tombol Preview Konsep maupun Review, hanya tombol Detail.
