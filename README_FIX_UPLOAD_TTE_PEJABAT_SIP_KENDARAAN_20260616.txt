Perbaikan alur SIP Kendaraan:

1. Setelah pejabat penerbit klik Setujui SIP, status SIP langsung menjadi TERBIT.
2. Pejabat penerbit tidak generate ulang konsep PDF.
3. Pada Detail SIP Kendaraan untuk role Kepala Biro/Sekretaris/Kepala Sentra/Kepala Balai ditambahkan fitur upload file SIP final yang sudah TTE pejabat penerbit.
4. File final tersebut disimpan pada file_signed_pdf dan dokumen_sip, sehingga preview Detail SIP menampilkan versi final terakhir yang sudah TTE pejabat penerbit.
5. Pengelola BMN tetap mengupload file TTE pegawai calon pemegang SIP sebelum pengajuan.
