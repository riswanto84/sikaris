# Perbaikan PSP - Checklist Dokumen Dipindahkan ke Biro Umum

Perubahan:
1. Bagian **Checklist Dokumen PSP** di halaman detail untuk role Sekjen dihilangkan.
2. Checklist dokumen dipindahkan ke panel **Verifikasi Usulan PSP - Biro Umum** dalam bentuk checkbox.
3. Checkbox Biro Umum meliputi:
   - Dokumen PSP SIKARIS Final/Gabungan
   - Surat Permohonan Satker
   - Surat Pengantar Eselon I
   - Daftar Kondisi Barang
   - Laporan Sub-Sub Kelompok
   - Surat Pernyataan Kepala Satker
4. Checklist berfungsi sebagai alat bantu verifikasi Biro Umum sebelum usulan diteruskan ke Sekjen.
5. Sekjen tetap hanya melihat dokumen utama/final dan panel penetapan PSP.

Tidak ada perubahan database dan tidak perlu migrasi.
